### Dataset Preprocessing

The **ACDC** dataset can be obtained from the [DPLR GitHub repository](https://github.com/lluyay/DPLR). More details about this dataset can be found on the [official ACDC website](https://www.creatis.insa-lyon.fr/Challenge/acdc/databases.html).

The **MS-CMRSEG** dataset can be obtained from the [DiffRect GitHub repository](https://github.com/CUHK-AIM-Group/DiffRect).
